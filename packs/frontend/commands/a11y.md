$ARGUMENTS のアクセシビリティチェック実行。引数なしなら http://localhost:3000

# 動作

1. **a11y-check** skill を起動
2. axe-core CLI で詳細violations
3. Lighthouse a11y でスコア
4. impact別（critical/serious/moderate/minor）に分類
5. 修正案を擬似コードで添えて提示
6. 手動確認推奨項目（自動検出不可なもの）も列挙

# 使用例

```
/a11y
/a11y http://localhost:3000/login
/a11y https://staging.example.com
```

# 閾値

- Lighthouse a11y score: 90+ 期待
- axe critical violations: 0 必須
- axe serious: 修正推奨

これらが満たせない場合はマージブロック相当の指摘として出力。
